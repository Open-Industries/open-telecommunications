# 6G Readiness — ITU-R IMT-2030 Framework

**Status honesty first**: 6G is not a finished standard. What exists is the ITU-R
framework — Recommendation **ITU-R M.2160** (framework and overall objectives of IMT-2030,
approved 2023) — plus ongoing study work in 3GPP (Releases 20/21) and research programs
worldwide. This platform is therefore **aligned to the IMT-2030 framework** and designed
so its scenarios land as configuration and policy, never as a rewrite. Any claim of "6G
compliance" would be false today; this document makes none.

## 1. The IMT-2030 usage scenarios (M.2160) and how the design anticipates them

| IMT-2030 scenario | Builds on | Anticipation in this platform |
|---|---|---|
| Immersive Communication | eMBB | HIGH_THROUGHPUT QoD profile; EMBB slice template with generous bitrate ceilings |
| Massive Communication | mMTC | MMTC slice type; session model tolerates very large device counts per slice (`maxDevices`) |
| Hyper Reliable and Low-Latency Communication | URLLC | URLLC slice type with explicit latency budgets in policy rules and SLA evaluation |
| Ubiquitous Connectivity | new | Generation-agnostic contexts: the same subscriber/session/charging model serves terrestrial and future non-terrestrial access through adapters |
| AI and Communication | new | Anomaly scoring and SLA evaluation are model-swappable functions behind stable contracts — rules today, ML models tomorrow, same CloudEvents |
| Integrated Sensing and Communication (ISAC) | new | `ISAC` is already a valid slice type and policy dimension (an ISAC policy evaluation is covered by tests as the DENIED baseline until rules are configured) |

## 2. IMT-2030 design principles reflected here

- **Sustainability**: scale-to-zero functions; no idle cost for assurance workloads.
- **Security and resilience by design**: ISO 27001/27002 control mapping; masked
  permanent identifiers; decisions with auditable reasons.
- **AI-native intent**: scoring/evaluation behind function contracts, so intelligence can
  evolve without touching the core contexts.
- **Ubiquity and interoperability**: CAMARA-standard exposure shapes; contracts first.

## 3. What adopters should expect to change when 3GPP 6G specifications land

New radio and core protocol work will land in network elements and adapters. The bounded
contexts, contracts discipline, charging integrity and privacy rules in this repository
are the parts designed to survive that transition unchanged.
